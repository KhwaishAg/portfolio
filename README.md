# Portfolio — Khwaish Agarwala

Brutalist/maximalist one-page portfolio. Pure frontend, no build step, no dependencies.

## Structure
- `index.html` — page structure
- `css/style.css` — all layout + styling (colors/fonts as CSS variables at the top)
- `js/content.js` — **edit this to change any text, projects, links, etc.**
- `js/script.js` — rendering + interactions, shouldn't need to touch for content changes
- `images/` — drop `profile.jpg` here for the hero photo slot

## Local preview
Just open `index.html` in a browser.

## Deploy
Connected to Vercel via GitHub — push to `main` and it auto-deploys.
